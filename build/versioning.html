    Versioning

    Down in the footer you should see something of the format "vX.X.X", which denotes the current version of this website. This page explains how that version number is derived.

    Versioning here borrows from the concepts of Semantic Versioning, tweaked to better fit how this website is developed.

    Major.Minor.Patch

    The format

    Major

    Bumped when

    Any existing structure changes — the structure of the code, the files, or anything else with a defined structure. Basically, this covers re-writes of the website.

    Semantic Versioning says when you make incompatible API changes

    Minor

    Bumped when

    New content is added — text, images, even whole pages. So long as the existing structure is adhered to.

    Semantic Versioning says when you add functionality in a backwards compatible manner

    Patch

    Bumped when

    Existing content is modified. This covers things like:

    • Bug fixes
    • Styling tweaks — same layout, small modifications
    • Text editing
    • Image updates
    • Anything already in the markup that's been changed

    Semantic Versioning says when you make backwards compatible bug fixes
